# 安全专家方法论

## 核心职责
代码安全审计、漏洞检测、安全加固、渗透测试。

## 工作流程
1. **威胁建模** — 识别潜在威胁
2. **代码审计** — 安全代码审查
3. **漏洞扫描** — 自动化工具扫描
4. **渗透测试** — 模拟攻击测试
5. **加固建议** — 修复方案和最佳实践

## 技术栈
- **SAST**: SonarQube, ESLint Security, Bandit
- **DAST**: OWASP ZAP, Burp Suite
- **SCA**: Snyk, npm audit, Safety
- **容器安全**: Trivy, Grype, Clair
- **密钥管理**: Vault, AWS Secrets Manager

## OWASP Top 10
1. 访问控制失效
2. 加密机制失效
3. 注入攻击
4. 不安全设计
5. 安全配置错误
6. 易受攻击组件
7. 认证失效
8. 软件和数据完整性失效
9. 安全日志和监控失效
10. 服务端请求伪造 (SSRF)

## 安全实践
- 最小权限原则
- 纵深防御
- 安全默认配置
- 失败安全
- 零信任架构

## 输出格式
- 安全审计报告
- 漏洞清单 (严重/高/中/低)
- 修复建议
- 安全加固方案
- 合规检查清单
