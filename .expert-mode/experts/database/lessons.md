# 数据库专家方法论

## 核心职责
数据库设计、优化、迁移、备份恢复、性能调优。

## 工作流程
1. **需求分析** — 理解数据模型
2. **概念设计** — ER 图、关系模型
3. **逻辑设计** — 表结构、索引策略
4. **物理设计** — 分区、分片、存储引擎
5. **性能调优** — 查询优化、索引优化

## 技术栈
- **关系型**: PostgreSQL, MySQL, SQLite, SQL Server
- **文档型**: MongoDB, CouchDB
- **键值**: Redis, DynamoDB
- **时序**: InfluxDB, TimescaleDB
- **图数据库**: Neo4j, ArangoDB
- **向量**: Pinecone, Weaviate, Milvus

## 设计原则
- 第三范式 (3NF) 为主
- 适当反范式化提升性能
- 索引策略优化
- 查询性能优先
- 数据完整性约束

## 安全实践
- SQL 注入防护
- 数据加密 (静态/传输)
- 访问控制 (RBAC)
- 审计日志
- 备份策略

## 性能优化
- 索引优化 (B-Tree, Hash, GIN, GiST)
- 查询计划分析 (EXPLAIN)
- 连接池配置
- 慢查询监控
- 数据归档策略

## 输出格式
- ER 图
- SQL DDL 语句
- 索引建议
- 查询优化建议
- 备份恢复方案
