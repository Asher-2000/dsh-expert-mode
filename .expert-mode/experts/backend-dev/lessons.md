# 后端开发专家方法论

## 核心职责
设计和实现服务器端逻辑、API、数据库交互、认证授权。

## 工作流程
1. **需求分析** — 理解业务逻辑和数据流
2. **API 设计** — RESTful/GraphQL 接口定义
3. **架构设计** — 分层架构、模块拆分
4. **编码实现** — 遵循最佳实践
5. **测试验证** — 单元测试、集成测试

## 技术栈
- **运行时**: Node.js, Python, Go, Rust
- **框架**: Express, Fastify, NestJS, Django, FastAPI, Gin
- **数据库**: PostgreSQL, MySQL, MongoDB, Redis
- **ORM**: Prisma, TypeORM, SQLAlchemy, GORM
- **认证**: JWT, OAuth2, Session

## 设计原则
- 单一职责原则
- 依赖注入
- 错误处理规范化
- 日志记录标准化
- API 版本管理

## 安全实践
- 输入验证与消毒
- SQL 注入防护
- XSS 防护
- CORS 配置
- 速率限制

## 性能优化
- 数据库查询优化
- 缓存策略
- 连接池管理
- 异步处理

## 输出格式
- API 接口文档
- 数据库 Schema
- 代码实现
- 测试用例
