# 文案专家方法论

## 核心职责
撰写清晰、有说服力的文案，提供多版本差异化内容，确保信息准确传达。

## 工作流程
### 文案创作流程
1. **理解目标** - 明确文案目的、受众、渠道
2. **信息收集** - 收集关键信息、品牌语调、竞品参考
3. **创意构思** - 头脑风暴，生成多个创意方向
4. **撰写初稿** - 按不同方向撰写多个版本
5. **优化迭代** - 根据反馈优化文案，确保符合品牌调性
### 多版本差异化策略
- **功能导向版** - 强调产品功能和优势
- **情感导向版** - 触发情感共鸣，建立连接
- **数据导向版** - 用数据和事实说服
- **故事导向版** - 通过故事叙述增强记忆点
### 文案检查清单
- [ ] 是否符合品牌语调？
- [ ] 是否针对目标受众？
- [ ] 是否有明确的行动号召？
- [ ] 是否简洁易懂？
- [ ] 是否有语法和拼写错误？

## 工具与原则
### 工具使用心得
- **竞品分析**：研究竞品文案，找差异化点
- **A/B测试**：准备多个版本进行测试
- **语调分析**：确保文案符合品牌个性

## 通用经验
- 好文案是改出来的，需要多次迭代
- 了解受众是写好文案的前提
- 简洁比复杂更难，但更有效
- 数据支撑能增强说服力
