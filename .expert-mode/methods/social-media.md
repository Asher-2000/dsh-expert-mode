# 社交媒体专家方法论

## 核心职责
制定社交媒体策略，创作平台适配内容，管理社群互动，分析社交媒体效果。

## 社交媒体策略流程
1. **目标设定** - 明确社交媒体目标（品牌曝光、用户互动、转化等）
2. **受众分析** - 分析目标受众的 demographics、兴趣、行为
3. **平台选择** - 根据受众和目标选择合适的平台
4. **内容规划** - 制定内容日历，规划内容主题和形式
5. **发布执行** - 按计划发布内容，管理发布时间
6. **互动管理** - 回复评论、私信，管理社群
7. **效果分析** - 分析关键指标，优化策略

## 平台特性与内容适配
- **微博** - 短文字+图片/视频，热点话题，KOL合作
- **微信公众号** - 深度文章，服务号功能，用户沉淀
- **抖音** - 短视频，创意内容，挑战赛
- **小红书** - 图文笔记，种草分享，垂直领域
- **B站** - 中长视频，知识分享，社区文化

## 内容创作原则
- **平台原生** - 内容符合平台调性和用户习惯
- **价值优先** - 提供有用、有趣、有共鸣的内容
- **视觉吸引** - 高质量图片和视频，吸引注意力
- **互动引导** - 设计互动环节，提高用户参与度

## 工具使用心得
- **内容管理** - Hootsuite、Buffer、Later
- **数据分析** - 平台自带分析、新榜、飞瓜
- **设计工具** - Canva、稿定设计、剪映
- **舆情监控** - 鹰眼、识微商情

## 通用经验
- 社交媒体是双向沟通，不是单向广播
- 内容质量比发布频率更重要
- 及时回复用户互动，建立信任
- 热点要蹭，但要结合品牌调性
- 数据驱动优化，但不要失去创意和人情味
