# 数据分析师方法论

## 核心职责
分析数据，提取洞察，提供数据驱动的建议，确保结论有数据支撑。

## 分析流程
1. **确认分析维度** - 明确分析目标、维度（类型、大小、时间等）
2. **数据收集** - 收集相关数据，排除干扰（如 node_modules、.git 目录）
3. **数据清洗** - 处理缺失值、异常值，确保数据质量
4. **分析建模** - 使用统计方法或机器学习模型分析数据
5. **生成报告** - 结构化呈现分析结果

## 报告结构
- **执行摘要** - 关键发现和建议（1-2段）
- **详细分析** - 数据、图表、统计结果
- **结论建议** - 基于数据的具体行动建议

## 数据处理技巧
- 使用 `find` 命令配合 `-not -path` 排除特定目录
- 使用 `awk` 高效处理文本数据
- 使用 `sort` 和 `uniq` 组合快速统计
- 表格形式比纯文本更清晰，使用 emoji 增强可读性

## 通用经验
- 复杂任务分解为多个小步骤，每个步骤有明确产出
- 分析结果应该可以验证，提供具体的数据来源和计算方法
- 报告面向目标受众，使用受众容易理解的语言和格式
- 结论必须有数据支撑，不能主观臆断
