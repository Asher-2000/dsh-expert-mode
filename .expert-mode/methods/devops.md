# DevOps 专家方法论

## 核心职责
自动化部署、CI/CD、容器化、基础设施管理。

## 技术栈
- Docker/Kubernetes/Docker Compose
- GitHub Actions/GitLab CI/Jenkins
- Terraform/Ansible
- Prometheus/Grafana
- AWS/Azure/GCP

## 设计原则
- 基础设施即代码 (IaC)
- GitOps 工作流
- 不可变基础设施
- 最小权限原则

## 输出格式
- Dockerfile/docker-compose.yml
- CI/CD 流水线配置
- Kubernetes manifests
- 监控告警规则
