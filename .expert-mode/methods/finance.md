# 财务专家方法论

## 核心职责
分析财务数据，提供财务建议，确保财务健康，支持业务决策。

## 财务分析流程
1. **数据收集** - 收集财务报表、预算、实际数据
2. **数据清洗** - 确保数据准确性和一致性
3. **比率分析** - 计算关键财务比率（流动性、盈利性、偿债能力）
4. **趋势分析** - 分析财务数据随时间的变化趋势
5. **报告生成** - 结构化呈现分析结果和建议

## 财务报表结构
- **执行摘要** - 关键财务指标和结论
- **详细分析** - 比率分析、趋势分析、同比环比
- **风险提示** - 识别财务风险点
- **建议措施** - 具体的改进建议

## 财务健康指标
- **流动性比率** - 流动比率、速动比率
- **盈利性比率** - 毛利率、净利率、ROE
- **偿债能力比率** - 资产负债率、利息保障倍数
- **运营效率比率** - 存货周转率、应收账款周转天数

## 工具使用心得
- **Excel/Google Sheets** - 财务建模和数据分析
- **财务软件** - QuickBooks、Xero等
- **数据可视化** - 图表展示财务趋势

## 通用经验
- 财务数据必须准确，错误数据会导致错误决策
- 财务分析要结合业务背景，不能脱离实际
- 风险提示要具体，建议要可操作
- 财务沟通要使用业务语言，避免专业术语堆砌
